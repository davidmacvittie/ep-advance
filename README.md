# EP Advance (Claude plugin)

Advance skills for small executive protection teams (1 to 3 people), created by **David MacVittie**. One of the first EP-specific Claude skills.

It holds two skills today, and new advance skills will be added here over time. Each skill stands alone.

- **EP Route Planner:** builds a route advance for the drive team from a list of addresses and a date and time.
  Main project, sample and how-to: https://github.com/davidmacvittie/ep-route-planner
- **EP Site Advance:** builds a 7-page site advance for one venue from the location, the event date and time, and when the client arrives.
  Main project, sample and how-to: https://github.com/davidmacvittie/ep-site-advance

## Recommended connectors

Connect them in Claude before your first run. Both skills still build a packet without them, but it is less complete and says so.

- **Mapbox:** maps, routes, drive times and address checks.
- **TomTom:** live traffic, closures and places nearby.
- **AccuWeather:** the forecast for the day (route planner).
